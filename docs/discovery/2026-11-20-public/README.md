# Project discovery for Compass

Sage researched how a Compass Project could refer to a workspace. Nova coordinated the research and Val owns the naming decision. Projects contain Castles. The following integration details remain proposals awaiting their owners.

| Area | Finding and proposal |
| --- | --- |
| Project identity | A folder path, a Project ID and a Castle ID have different meanings. The first read-only adapter could display Cave’s Project listing while keeping its identifiers distinct. |
| Host ownership | Compass displays a projection. Folder registration and execution placement belong to the relevant Host and Cave owners. |
| Transport | The static site has no approved live connection. Keep the live view unavailable until the owners provide a supported transport. |
| Projection freshness | A read-only adapter should indicate when a snapshot is stale, reconciling or incompatible. |

The [decision register](../../handoff/11-open-decisions.md) tracks owner decisions. This release summary was prepared from Sage’s November 19 discovery packet. Maintainers retain the original packet and its recorded provenance separately.
